# 🚀 JavaScript Mini Projects

This repository contains a collection of beginner-friendly JavaScript projects that I built while learning and practicing core programming concepts.  
Each project is small, interactive, and focuses on strengthening problem-solving and JavaScript fundamentals.

---

## 📂 Projects Included

- **Age Counting** → Calculate a person's age from their birth year.  
- **Dice Roller Program** → Simulates rolling a dice with random values.  
- **String Operations** → Perform basic string manipulations and functions.  
- **Temperature Conversion Program** → Convert temperatures between Celsius, Fahrenheit, and Kelvin.  
- **Checked Option** → Handles checkbox/radio button options dynamically.  
- **Expense Tracker** → Track expenses with simple calculations and balance updates.  
- **Guessing Number Game** → Fun number guessing game using random number generation.  
- **Ternary Operator Demo** → Examples of using ternary operators in JavaScript.

---

## 🛠️ Tech Stack

- **Languages:** JavaScript (ES6+), HTML5, CSS3  
- **Concepts Covered:** DOM Manipulation, Functions, Events, Conditional Logic, Randomization  

---

## 📸 Preview

Each folder contains the respective project with source code.  
Open the HTML file in your browser to run and test the project.
